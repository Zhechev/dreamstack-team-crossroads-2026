# ADR-018 Name, brand and iOS-style UI

## Context
One consistent look across app, slides and video, built in minutes; normal people trust familiar interfaces.

## Decision
The product is **Citable**; the team is DreamStack. Brand: trustworthy legal-tech — serif wordmark, **§** mark, ink/paper/rust palette. Interface: **iOS-like** patterns. Details in [[Brand]].

## Consequences
One Lovable style prompt for every screen. We copy the feel of iOS, never Apple assets.

## Rejected
Crypto-native dark UI; playful consumer style.
